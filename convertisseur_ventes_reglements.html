Convertisseur factures + règlements → écritures comptables

Génère les écritures de ventes (vente / TVA / client) et les écritures d'encaissement (client / 58000) à partir de deux fichiers CSV (séparateur ;). Tout se passe localement dans votre navigateur, aucun fichier n'est envoyé.

1. Fichiers d'entrée
Colonnes : Type, Date, Numéro, Objet, Total HT, Total TVA, Total TTC (et si présentes : Référence du client, Nom du client).
Colonnes : NUMERO, DATE REGLEMENT, FACTURE(s) REGLEE(s), MONTANT IMPUTE (et si présentes : MODE REGLEMENT, MONTANT, COMPTE(s) CLIENT, NOM(s) CAVALIER(s), ETAT, LIBELLE).
Encodage UTF-8 ou Windows-1252 détecté automatiquement. Le fichier de sortie reprend l'encodage du fichier factures.
2. Paramètres
TVA : 5,5 % → 445715 (code v), 10 % → 445712 (code p), 20 % → 445726 (code Y).
